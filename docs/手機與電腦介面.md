# 手機與電腦介面

本版在較窄的畫面使用手機／平板版型，寬畫面保留桌機多欄介面。不需要另外切換帳號或搬移專案。

## 手機與平板

- 頂部保留儲存、媒體／編輯／錄製模式及匯出入口。
- 編輯模式下以「預覽、AI 助理、屬性、時間軸」切換主要工作區，避免側欄擠壓影片。
- 點「時間軸」可展開獨立時間軸。橫向窄螢幕先保留主要工作區，時間軸透過同一按鈕開啟。
- 更多檔案操作收在「編輯器選單」。手機的按鈕與播放進度控制已放大；實際觸控與軟鍵盤仍待實體手機驗證。
- 匯出按鈕在沒有影片素材時會停用，版面可見不代表完整匯出流程已通過。

## 電腦

寬畫面維持原本的 AI 側欄、影片預覽、浮動屬性面板與下方時間軸，保留原來的側欄與時間軸調整功能。手機面板切換列在寬畫面隱藏。

## 這與手機連線不同

RWD 只調整操作介面。目前程式仍在 Mac 上執行，沒有可公開試用的手機網址。手機無法用自己的 127.0.0.1 連到 Mac，也不能直接執行 Codex CLI。

本次只使用本機隔離預覽檢查；未對區網或外網開放服務，未上傳、未建立憑證。若之後要自己的手機操控自己的 Mac，需要另外確認私人連線、HTTPS 與裝置存取權限，並完成手機端實測。

朋友若要使用自己的 Codex，應由各自在自己的 Mac 執行程式；不能共用站主的 Codex 登入環境。
